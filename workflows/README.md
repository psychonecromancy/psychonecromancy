# workflows/

Exported n8n workflow JSON. This is the source of truth for pipeline
orchestration — not the n8n canvas on the VPS.

When you change a workflow in the n8n UI, export it (Download from the
workflow menu, or via the n8n API) and commit the JSON here before
considering the change done.

Empty until Phase 1 produces the first working workflow. See
[../BUILD_PLAN.md](../BUILD_PLAN.md).
