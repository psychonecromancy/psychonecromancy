# comfy/

Exported ComfyUI graphs, in **API format** (Settings → Enable Dev Mode
Options in ComfyUI, then "Save (API Format)" from the workflow menu — the
default export format is not what n8n's `POST /prompt` expects).

Empty until Phase 1 produces the first working graph. See
[../BUILD_PLAN.md](../BUILD_PLAN.md) and
[../docs/03-infrastructure.md](../docs/03-infrastructure.md).
